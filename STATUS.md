### 13.11.2026 — Claude: 1.7d DYNAMIC TEST (Issue #4)
- Ветка `claude/1.7d-dynamic` = PR #2 (`6f03c90`, с историей) + `feature/ui-redesign-studio` + исправления.
- Исправления Dynamic Cut по ревью:
  - банк WET работает со связанным детектором: ранние и поздние отражения анализируются вместе и режутся одинаково;
  - порог считается по уровню шины, как его показывает анализатор;
  - детектор не сбрасывается при смене частоты и Q;
  - полоса не пропадает при автоматизации типа;
  - восстановление после NaN, точный возврат к 0 dB;
  - живое ослабление передаётся в интерфейс через атомарные значения.
- UI:
  - лампы за обеими решётками: кэшированные слои, яркость зависит от HARMONIC COLOR ON / DRIVE / MIX и входного уровня;
  - на графике REVERB EQ: янтарная кривая и подпись «−x dB»;
  - удержанные пики остаются на месте.
- Своя папка пресетов 1.7d.
- Тесты: 153 проверки, ошибок 0:
  - срез по банкам, соседние полосы не меняются;
  - нет щелчков при ON/OFF и при развёртке порога;
  - 44.1 / 48 / 96 kHz, размеры блока, смена частоты;
  - моно, bypass, состояние, NaN, тишина, CPU (+0,6–2 % реального времени на 24 полосы);
  - удержание пиков.
- 1.7d с выключенным Dynamic Cut = 1.6 = 1.5: 32 рендера бит в бит.
- Прослушивание: `MasterSpace17dTests --dyn-renders <папка>` (OFF / ON / разница).
