Название активного пресета показывать полностью, категории Rooms/Chambers и др. сверху, sidechain/AUX ниже.
- HARMONIC COLOR: горизонтальный SATURATION MIX под ON/OFF. Лампы при MIX 0% почти не горят, при 100% насыщенный красно-оранжевый свет. M/S — независимые MID/SIDE, STEREO должен звучать как прежде.
- M/S OUTPUT COMPRESSOR: WET ONLY по умолчанию, альтернативный FULL OUTPUT; отдельные MID/SIDE, COMP ON. Уже есть Smart Ducker, второй дюкер не добавлять. Компрессор не должен менять dry в WET ONLY.
- Resonance Guard/Dynamic Cut: шесть слотов ромбов, новые пики первыми, удержание 5 с, click/drag вниз, в динамическом режиме drag вниз задаёт threshold. Не менять согласованную обработку.
- EQ: настоящий раздельный WET/EARLY/LATE, FFT, Spectrum Freeze. Исторически пользователь хотел простой UI с четырьмя белыми точками (low shelf/HP, 2 bell с Q, high shelf/LP), без перегруженной правой панели. Текущий движок содержит больше банков/полос и динамический EQ; не удалять их и не переделывать текущий UI без отдельной задачи.
- SIGNAL RAILS: INPUT слева под DECAY синий, OUTPUT справа под MIX золотой, L/R RMS 300 ms, peak ~0.8 s, красный от -3 dBFS, INPUT pre, OUTPUT post всего тракта, плавное затухание при остановке.
- Spatial Position: выдвижная панель для front/back и left/right. Сохранять глубину, соотношение direct/ER/late, decay, тембр и стерео.
- Будущее, не включать в текущий релиз без отдельного задания: hover-подсказки RU/EN с задержкой, On/Off и Simple/Detailed; Training / Space Academy с пошаговыми примерами и аудио; PDF-инструкция с картинками; SPACE PRINT, SPACE MORPH; дальнейший Master Astakhov Hub, Comp Academy, EQ Academy. Не считать эти идеи реализованными.

## 4. Текущая цель: LEVEL MATCH
Пользователь услышал сильное падение громкости: при открытии плагина звук должен быть по уровню примерно как BYPASS. Измерения старой 1.8: новый экземпляр MIX 35% около -4 LU; LeadVox Studio Room (MIX 100%, OUTPUT -3.6 dB, сниженные ER/LATE) -9.4…-11 LU; некоторые ER-пресеты около 0 LU. Причина не только DEPTH: directGain около 0.6033 при depth35, equal-power dry cos(0.35*pi/2)=0.85264, плюс wet, level lock и output. LEVEL LOCK сохраняет относительный уровень референсной глубины, не равенство с BYPASS. A/B MATCH выравнивает B относительно A, это отдельная функция.

Требования: статическая компенсация на основе настроек/эталонной калибровки, НЕ измерение громкости входящего живого аудио в реальном времени, НЕ AGC/компрессор/лимитер. Общий L/R gain, диапазон -6…+12 dB, цель 0 LU к BYPASS на эталоне при OUTPUT 0 и отключённой динамике. Не обещать точное равенство на любых сигналах. Не менять dry/wet, положение, decay, stereo, GR, характер хвоста. AUX и отключённый LEVEL MATCH — прежний сигнал бит в бит в установившемся состоянии. Без дополнительной задержки. OUTPUT остаётся творческим ручным trim, не компенсировать его автоматически. Никакого скрытого лимитера; показать риск headroom при boost. Gain после WET ONLY/FULL OUTPUT compressor и A/B trim, до OUTPUT meter; исключить двойную компенсацию A/B. В существующем processBlock A/B trim до FULL OUTPUT compressor; не перестраивать старый порядок при OFF.

Ранее предложено: включать LEVEL MATCH для новых INSERT, OFF при восстановлении старых состояний; отдельные INSERT/WET варианты LeadVox, обнулить только служебный trim в заводских пресетах; не добавлять safety ceiling. Пользователь согласовал продолжение разработки и цель равной громкости, но нет отдельного явного подтверждения переписывания заводских пресетов и конкретной миграции ON/OFF. Сохранить старые пресеты и состояния; предложенные изменения проверить в отдельном эксперименте, не делать необратимых изменений. Не задавать повторные вопросы о уже согласованном. 

## 5. Реальный прогресс, а не обещания
- Source/MasterSpace/AutoLevelMatch.h — standalone Gram matrix estimate E=a^TQa, cross terms DIRECT/EARLY/LATE, PSD checks, near-zero/NaN fallback, linked stereo gain с sample-based ramp. Коммит 02402e7.
- ALMCalibration.h — offline covariance accumulator, требует синхронные K-weighted отсчёты. Не BS.1770 gated integrated loudness сам по себе. Коммит a1fadda.
- ALMCalibrationMailbox.h — единое lock-free 64-bit atomic слово (generation, gain, valid/limited); stale worker rejection. Коммит 646a034. tests/alm_mailbox_tests.cpp (85dc881) есть, отдельный запуск не доказан, включить его в CI.
- tests/auto_level_match_core_tests.cpp и .github/workflows/level-match-core.yml: macOS Intel + Linux, ASan/UBSan. Первоначальный тест сравнивал 2.0 точно после float dB roundtrip, исправлен в ce6e068 без ослабления exact OFF/AUX. Последний подтверждённый core run 45650640714 — success.
- tests/alm_calibration_survey.cpp, tests/alm-survey.cmake, .github/workflows/alm-calibration.yml: отдельная диагностическая сборка движка. Рендеры DIRECT/ER/LATE на одном эталоне сравниваются с полной обработкой. Подтверждённый run 45650583620: 48 kHz +3.979 dB (model=actual, error 0.000 по округлению, residual -138.95 dB), 96 kHz +4.061 dB (error 0.000, residual -139.01 dB). Более поздний run 45650640556 — success. Это только проверенный default-подобный сценарий, динамика и EQ отключены, не все пресеты/режимы. Не считать это интеграцией или доказательством AU.
- Реальный процессор, UI, CMake product target и установщик ещё НЕ изменены для LEVEL MATCH. Нет готового AU или ZIP. В прошлых попытках GitHub API вернул ReadTimeout и repository rule timeout 409; не обходить правила, проверять фактический head перед повтором. Подробности в PR #14, комментарий 7167560405. Документ STATUS.md частично отстаёт от фактических коммитов/CI.
